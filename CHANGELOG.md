# Changelog

## 0.1.0

First release.

- Search Analytics, URL Inspection and Sitemaps tools for Google Search Console.
- SEO analysis tools: performance summary, striking-distance quick wins, CTR opportunities, period comparison, keyword cannibalization, single-page analysis.
- On-page audit of live URLs, with query coverage checks.
- Browser OAuth sign-in from the CLI or from inside Claude; service account and Application Default Credentials support.
- Prompts: `seo_audit`, `optimize_page`, `investigate_traffic_drop`.
- Claude Desktop bundle (`.mcpb`).
